# Spinner Clicker

A minimalist browser-based RNG spinner clicker game built with vanilla HTML, CSS, and JavaScript.

🎮 **Play the game:**  
[Play Spinner Clicker](https://your-username.github.io/your-repo-name/)

## Features

- Color-coded pie-chart spinner with rarity slices (Common → Legendary).
- Multiple spinner types (e.g. Wood and beyond), each with its own look and odds tweaks.
- Fixed themed pointer arrow that matches the current spinner type.
- Click-to-spin and auto-spin options.
- Upgrades and spinner shop to improve income and odds over time.
- Progress and unlocks saved with `localStorage`.
- Fully client-side, no frameworks, just HTML/CSS/JS.

## How to Play

1. Click the **Spin** button (or use the keyboard shortcut if enabled) to spin the wheel.
2. When the wheel stops, you earn rewards based on the rarity you land on.
3. Spend your money on:
   - **Upgrades** to increase rewards.
   - **New spinner types** that look better and slightly improve odds for higher rarities.
4. Keep spinning to reach higher totals, unlock better spinners, and chase rare/legendary hits.

## Controls

- **Mouse / Touch**
  - Click / tap the **Spin** button to spin.
  - Click UI buttons to buy upgrades and change spinner types.
- **Keyboard** (if enabled in the project)
  - `Enter` – Spin
  - `U` – Open upgrades
  - `S` – Open spinner types
  - `B` – Toggle auto-spin
